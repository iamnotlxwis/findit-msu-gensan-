# FindIt — MSU Gensan Lost & Found

A minimalist campus lost and found board for the MSU Gensan community.

## Project structure

- `index.html` — homepage
- `css/style.css` — responsive monochrome styles
- `js/app.js` — sample listings, search, filters, and modal interactions

## Run locally

Open `index.html` in a browser. No build step is required.

## Prototype status

This is a front-end prototype. The listings are sample data. Firebase Authentication, verified school-email registration, Firestore storage, image uploads, and admin moderation are not connected yet.

Registration is intended for verified `@msugensan.edu.ph` addresses. The current email check is only a front-end demonstration, not secure authentication.
